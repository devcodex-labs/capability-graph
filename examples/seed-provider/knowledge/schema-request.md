# 请求 Schema

请求 Schema 描述哪些字段可接受、哪些字段必填及字段约束。Schema 类型和实际项目中的具体 Schema 对象需要区分，不能从静态 Catalog 推断项目已定义哪些字段。

## 校验要求

- 从应用的真实输入合同确定字段及约束，不凭示例名称补造规则。
- 覆盖合法输入、缺字段、空值、类型不匹配和边界值。是否接受未知字段由应用合同决定。
- 当同一 Schema 被多个路由使用时，评估现有消费者，不能因为修改一个路由就静默改变所有消费者。
- 更新知识引用后重新加载能力定义；只修改本文件正文时，下次读取会获得新的内容身份，不必改变静态能力修订。

向量召回或知识检索是可选接入。本地直接读取本文不依赖模型、数据库或网络。
