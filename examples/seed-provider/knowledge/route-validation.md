# 路由输入校验

在路由边界验证输入，业务处理器只接收满足约定的数据。这里描述接入知识，不提供 Core 内的执行器。

## 给 POST /users 增加校验

1. 选中 `route.validation`，用关系查询确认其分类、具体化和参考对象。
2. 显式补选 `schema.request`。参考边不会自动赋予知识检索范围。
3. 查询目标项目/环境中的 `route.http` 实例，核对 POST /users 的来源与新鲜度。
4. 读取本文件和请求 Schema 文档，在宿主代码中实现输入验证。
5. 在宿主中验证正常输入、缺少必填字段、字段类型不匹配及已有响应契约。Core 返回知识不代表业务验证已经通过。

保留原路由身份和分派规则，除非需求明确改变接口。调用方负责决定错误响应格式，能力定义不替代应用合同。
