# 1.0.0

Capability Graph 的首个公开版本，提供协议无关的 Provider 能力建模、渐进发现与知识导航基础。

## Core

- 文件权威加载、统一校验、正式图、联合目录、Provider 范围和 current/previous 静态修订。
- 平坦能力摘要目录、按需详情、六类关系查询、分页、预算、部分结果和稳定错误语义。
- 本地知识读取，以及数据库权威、能力召回、知识检索和 Runtime 的公开扩展合同。
- 真实 Seed、普通 API、独立私有 MCP 示例和 Node.js HTTP Runtime 参考。

## 质量与分发

- npm 包身份统一为 `@devcodex/capability-graph`；GitHub 仓库与 Pages 继续使用 `devcodex-labs/capability-graph`。
- 标准 pack 自动清理构建，覆盖无 dist 源码、残留旧产物、独立安装和公开类型消费。
- Core CI 覆盖 Windows/Linux 与 Node 20.19.0、22.12.0。
- 用户文档提供入门教程、概念、操作指南、集成、示例、公共契约 Reference 和故障排查，以及搜索、Sitemap、AI 文本和响应式浏览器验证；顶部仅保留版本与 GitHub，左侧按七个中文分区默认展开，并提供首页直达示例、可独立运行的 First Provider 路径和移动端键盘/焦点语义。

## 边界

- Core 不执行第三方能力，也不提供统一 MCP Server。
- 数据库、向量/RAG 和远程知识 Reader 在本版本提供合同，不附具体后端。
- VextJS 集成仅提供概念方案，待真实框架接入后升级状态。
