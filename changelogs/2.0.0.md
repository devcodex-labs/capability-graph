# 2.0.0

主包收敛为文件定义驱动的静态能力图谱与关联文档读取。这是破坏性主版本调整，旧实现保留在 `v1.1.0` tag 和已发布的 1.1.0 包中。

## 升级清单

| 移除内容 | 调整方式 |
|---|---|
| `authority.kind = "database"`、`DatabaseAuthorityAdapter`、`DatabaseReadView` 与公开原始数据库记录/分页合同 | 从宿主导出正式 JSON 定义，配置文件来源；不要把驱动适配器继续传入 Core |
| `retrieveCapabilities()`、`CapabilityRetriever`、`DiscoveryAdapter` | 使用 `listCatalog` 结构化过滤及明确能力 ID；自然语言召回交由独立模块 |
| `queryKnowledge()`、`KnowledgeRetriever`、搜索目标/命中/索引证据/失效合同 | 通过文档引用及公开分页读取取得原文；索引、排名和 RAG 由独立模块负责 |
| `queryRuntime()`、`RuntimeAdapter`、实例/观察/运行修订/兼容合同 | 业务状态查询由宿主自己的 API 管理 |
| `runtimeAdapters`、`knowledgeRetriever`、`capabilityRetriever` 配置 | 删除字段；即使值为 `undefined`，旧字段也明确报 `CG_CONFIG_INCOMPLETE` |
| `budgets.runtime`、`budgets.queryKnowledge`、`budgets.retrieveCapabilities` | 删除已移除操作的预算；未知分组明确失败 |
| Runtime/检索专属错误及未使用的 `CG_TIMEOUT` 和 `use_retrieval` / `reduce_document` 动作 | 更新错误分支；Reader 错误仍保留 |
| `CurrentCapabilityView.runtime` | 结果仅保留能力修订和实际读取的文档内容身份 |
| `examples/seed-runtime` | HTTP 文档参考迁至 `examples/http-reader`，检索和运行采集示例移出当前维护范围 |
| Seed MCP 三个可选查询工具 | 工具清单由 14 个减至 11 个；独立主入口示例仍为 5 个 |

Provider Schema、能力 ID、四种关系和八种正反向查询、`requires` 闭包、Collection/Specification、目录与 legacy 布局、scope、修订及 reload 行为继续保留。相同定义的规范化静态身份保持一致；升级后重新开始分页，旧主版本游标不承诺可复用。

本地目录、明确获准的外部目录、真实安装包根和 URL Reader 均保留。文档总大小不设准入上限；全文返回和单页/响应/缓存仍有独立资源预算，内容变化拒绝旧游标。强来源证明与范围读取继续保障原字节分页。

尚无独立 RAG 替代包；已有消费者可以固定 1.1.0，或将超出图谱职责的调用移至自己的模块。此次源码调整不会自行创建 tag、发布 npm 或更新公开站点。
