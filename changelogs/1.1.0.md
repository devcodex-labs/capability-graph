# 1.1.0

本记录对应 1.1.0。安装可用性以 Registry 的确切版本查询为准；发布使用匹配的包与站点制品。

- 显式 `definitionLayout: 'directory'` 收集 `capabilities/**/*.json`，不再要求 `.capability` 后缀。旧配置缺省 `legacy`；同记录和 locator 的迁移保留逻辑身份及 Static Revision。混用、嵌套 Provider、错误目录、链接定义、大小写冲突和重复身份明确失败。
- 每 Provider 的 `knowledgeRoots` 可绑定获准目录或实际安装包；`relative-file` 的 `root` 引用别名，支持 scoped/pnpm、中文和空格，保留真实路径边界及私有来源上下文。
- 正文分页不设文档总大小准入门槛；模型选择范围和是否续读。全文与分页保留原始 BOM/CRLF，MD/MDX MIME 一致，全文哈希与本页哈希分别表达。
- 全文单篇预算 `read.maxBytes` 保持兼容，新增独立 `read.maxPageBytes` 控制分页/流块；段落边界采用线性扫描并保留 CRLF 原始偏移。
- KnowledgeReader 新增可选 isContentCurrent 强来源核验合同；正文续页可复用有界私有副本，HTTP 参考用条件 HEAD/强 ETag，减少重复完整扫描。普通文件、弱验证器及缓存未命中继续完整核验，内容变化拒绝旧游标。缓存每实例最多 4 MiB、16 条，文档不设大小准入限制。
- KnowledgeReader 新增可选 readRange；较大正文的续页通过首次完整扫描留下的有界分块哈希独立验证范围，HTTP 参考读取仓库外磁盘快照，避免超过内存正文缓存容量后反复全文扫描。来源、范围或证明不可用时保持完整核验回退。
- 外部检索即使不调用 access，也核验全部来源与命中范围，包括零命中。数据库 Catalog 与全部八类关系检查完整性，漏项和假空流明确失败。
- Runtime 保留白名单修订/上下文错误及安全动作，移除 Adapter 私有 message/details；期限或未知异常仍为 unavailable。
- HTTP 与词法检索源码参考增加宿主代理 Agent、强 ETag 完整快照复用和受预算约束的流式 Top-K。缓存预算不限制文档大小。
- VextJS 固定源/安装构建指纹、原生回读、官方章节映射、独立召回门槛与 MonSQLize 双 Provider 真实来源矩阵可复现。来源材料与作者关联分别溯源，文档验证不代表功能执行或 Agent 成功。
- VextJS verified 导出绑定物理来源根、固定提交与逐篇 Git blob；CI 增加全部 91 篇官方文档、46 个主题的 63 条独立任务，以及全新安装项目业务验收。参考能力检索使用中文词组、常见否定处理和词项加权，仍是有限词法参考。
- 文本参考检索器增量统计流式 UTF-8 字节，空词项块不占用缓存条目；性能基准按实际索引缓存状态区分冷查询、命中、容量溢出及零命中，持续核验来源和原始片段偏移。

- VextJS 统一标记为固定来源、有前置条件的可运行源码示例；首次导出和发现教程直接还原为真实安装消费者验证，检索任务与 Jobs 的证明范围分别说明。
- 站点改善浅色/深色文字对比度、文档选项语义、隐藏锚点与宽表格键盘操作；加入独立无障碍检查与常见任务词搜索回归。
- 安装文案使用确切版本查询与固定提交源码回退，补齐 1.0.1 升级路径；发布校验拒绝过时文案，发布门禁复用同一冻结提交的 Core、VextJS、Docs 兼容工作流。
- 开发工具升级 YAML，并覆盖 FTP 间接依赖的安全版本；生产依赖与主包入口保持原范围。

迁移：旧定义无需批量重命名；使用目录模式时迁移文件并同步配置，不混用旧目录外定义。新增接口需安装 1.1.0；是否已发布以 Registry 查询为准，未发布时使用同提交源码构建。外部知识索引需实际来源 Reader；数据库 Adapter 需完整支持八类关系。失效的索引/游标由宿主显式刷新和 invalidate/rebuild，Core 不自动更新后端。

主包仍为单一 ESM 入口；VextJS、HTTP、MCP 是源码参考，未新增主包专用后端导出。开发记录见 [unreleased.md](unreleased.md)。
