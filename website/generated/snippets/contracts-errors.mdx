## 完整签名与字段

以下由公开声明生成。接口继承字段已展开；`?` 表示可省略，**不表示可传 null**。类型不能表达的默认值、值域、预算与失败语义以本页正文为准。类仅列公开方法；绑定对象必须由 forProvider 获取。

### CapabilityGraphError 合同

```ts
class CapabilityGraphError {
  constructor(code: ErrorCode, init: {
    nextAction: NextAction;
    message?: string;
    details?: Record<string, unknown>;

}
```

| 字段/方法 | 类型 | 必填 |
|---|---|---|
| `code` | `ErrorCode` | 是 |
| `nextAction` | `NextAction` | 是 |
| `details` | `Readonly<Record<string, unknown>>` | 否 |
| `name` | `string` | 是 |
| `message` | `string` | 是 |
| `stack` | `string` | 否 |
| `cause` | `unknown` | 否 |
