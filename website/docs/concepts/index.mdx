## 产品边界

Capability Graph 是本地优先、协议无关的能力发现基础设施：校验定义、关系、修订、范围、知识引用和 Runtime 观察，不执行业务能力，也不扫描任意框架源码猜能力。

### 责任链

Provider 作者维护权威定义与 Adapter；Core 校验并提供查询原语；Provider-owned API/MCP 负责协议、认证、工具设计与规范投递；Agent 根据意图选择能力；业务系统执行真正的路由、构建或部署。Core 不是统一 MCP Server、任务编排器、权限系统或执行沙箱。

### 当前边界

文件 Authority、本地 Document、Seed API/MCP 和真实 HTTP Runtime 参考可运行；数据库 Authority、检索及远程 Reader 是扩展合同，不附真实后端。集成前用[集成入口](../integrations/index)核对实施状态和自己需要提供的组件。
