# 使用多个 Provider

<span className="cg-status">可用</span>

在 `open()` 时声明宿主允许、集成启用和每个 Provider 的唯一 Authority：

前置为最小 G0 的 providers/acme-http 两个定义。另建 providers/acme-database，保存以下两个完整 JSON。acme.database 只是示例身份，仍用文件 Authority，不代表提供真实数据库后端。

```json title="providers/acme-database/provider.json"
{
  "providerId": "acme.database",
  "name": "Acme Database",
  "version": "0.1.0"
}
```

```json title="providers/acme-database/query.capability.json"
{
  "capabilityId": "query",
  "name": "Database query",
  "description": "Describe how to query application data.",
  "whenToUse": "The task needs a database query capability."
}
```

以下 TypeScript 代码放在安装项目根；两个 rootDir 都相对当前脚本。使用 JavaScript 时原样保存为 .mjs 也可运行：

```ts
import { fileURLToPath } from 'node:url';
import { CapabilityGraph } from '@devcodex/capability-graph';

const graph = await CapabilityGraph.open({
  hostAllowedProviders: ['acme.http', 'acme.database'],
  integrationEnabledProviders: ['acme.http', 'acme.database'],
  providers: [
    { providerId: 'acme.http', authority: { kind: 'file',
      rootDir: fileURLToPath(new URL('./providers/acme-http/', import.meta.url)) } },
    { providerId: 'acme.database', authority: { kind: 'file',
      rootDir: fileURLToPath(new URL('./providers/acme-database/', import.meta.url)) } }
  ]
});
try {
  const page = await graph.listCatalog({
    requestProviderScope: ['acme.http', 'acme.database'], limit: 40
  });
  const http = graph.forProvider('acme.http');
  const detail = await http.getCapabilities(['route']);
  console.log({ ids: page.items.map(({ qualifiedId }) => qualifiedId),
    meta: page.meta, nextCursor: page.nextCursor, detail });
} finally {
  await graph.close();
}
```

预期 ids 恰为 acme.database::query、acme.http::route，meta.scope 含两者，staticRevisionByProvider 分别记录来源修订。检查完整性/游标与 detail.results[0].ok；多个 Provider 不共用单个 requiredStaticRevision，选择一个后用绑定查询取得真实修订。

联合目录保留二元身份，不创建跨 Provider 图边，不把相同 capabilityId 合并。接入方负责租户认证，requestProviderScope 只能收窄有效范围。

## 选择之后

以下是上面 try 内查询的替换片段，不能在 finally 已关闭之后继续执行；G0 查询 route，不假定 route.http 已定义：

```ts
const selectedProvider = graph.forProvider('acme.http');
const selectedDetail = await selectedProvider.getCapabilities(['route']);
```

单个未指定修订的来源故障应被隔离，不清空其他 Provider 的合法候选。指定修订不可读时则明确失败。跨 Provider 组合由 Agent 或上层工作流完成。
