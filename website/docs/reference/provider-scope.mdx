# Provider 作用域 API

<span className="cg-status">可用</span>

Open 阶段的 Effective Provider Scope 为 `hostAllowedProviders ∩ integrationEnabledProviders`。查询提供 `requestProviderScope` 时再求一次交集。

规则：

- 请求范围只能收窄；包含未允许 Provider 时返回 `CG_SCOPE_DENIED`；
- 显式空宿主/集成范围与空 `providers` 是合法空配置；
- 有效启用范围中的每个 Provider 必须恰有一个 Authority；
- `BoundProviderGraph` 固定单 Provider，拒绝 `requestProviderScope`；
- capabilityId prefix、parent 和类型过滤不是授权；
- Adapter 仍运行在当前进程中，scope 不提供系统级沙箱。
