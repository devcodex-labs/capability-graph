# 身份模型

<span className="cg-status">可用</span>

```ts
interface CanonicalCapabilityId {
  providerId: string;
  capabilityId: string;
}
```

`QualifiedCapabilityId` 是显示字符串，正式分隔符 `QUALIFIED_SEPARATOR` 为 `::`。导出的辅助函数：

- `isId()` / `isKnowledgeId()`：检查合法 ID；
- `formatQualifiedId()`：从二元身份生成可逆显示串；
- `parseQualifiedId()`：只按正式分隔符解析；
- `equalId()`：比较二元身份；
- `idKey()`：生成内部稳定键。

不绑定 Provider 的查询必须使用完整二元身份。`{ capabilityId }` 短形式只在 `BoundProviderGraph` 中合法。Provider 版本不是身份的一部分。
