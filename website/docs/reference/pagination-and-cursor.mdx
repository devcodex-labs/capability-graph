# Pagination and Cursor

<span className="cg-status">Available</span>

游标绑定原请求的范围、过滤、limit 和修订。续页时必须保留这些条件；来源修订变化或游标不匹配会返回明确错误。

最终公开游标编码后最多 32,768 个 base64url 字符。输入超过上限为 `CG_INPUT_INVALID`；Adapter 游标或组合游标导致输出超限时为 `CG_BUDGET_EXCEEDED`，不会返回无法继续使用的游标。

邻居的六个关系组各自分页。下一次只提交仍有 `nextCursor` 的 `kinds` 和对应 `cursors`，已完成组无需重复。

页大小和总字节预算同时生效。提高响应字节预算不会放宽公开游标长度上限。
