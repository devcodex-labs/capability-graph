# CapabilityRetriever 接口

<span className="cg-status">仅合同</span>

输入：查询文本、允许的 Provider IDs、每个 Provider 的当前 Static Revision 和候选上限。输出候选身份、可选 score 与 `sourceStaticRevision`。

Core 按 Adapter 原始顺序生成一基 `rank`。候选被拒绝时保留排名间隙，合法项不重排。Core 会拒绝：

- 范围外 Provider；
- 不存在的能力；
- 来源修订与可读权威视图不一致；
- 过大或超数量候选；
- 违反合同的 Adapter 返回。

未指定修订时，一个来源不可读不应清空其他 Provider 的合法候选；指定修订不可读时查询级失败。
