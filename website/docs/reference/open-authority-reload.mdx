# 打开、Authority 与重新加载

<span className="cg-status">可用</span>

## OpenConfig

```ts
interface OpenConfig {
  hostAllowedProviders: readonly string[];
  integrationEnabledProviders: readonly string[];
  providers: readonly ProviderLoadSpec[];
  budgets?: BudgetOverrides;
  runtimeAdapters?: readonly RuntimeAdapter[];
  readers?: readonly KnowledgeReader[];
  knowledgeRetriever?: KnowledgeRetriever;
  capabilityRetriever?: CapabilityRetriever;
}
```

## AuthoritySpec

```ts
type AuthoritySpec =
  | { kind: 'file'; rootDir: string }
  | { kind: 'database'; adapter: DatabaseAuthorityAdapter };
```

每个有效启用 Provider 必须恰有一个 Authority。文件根在 `open()` 时解析并固定；数据库 read view 在交给 Core 后成为稳定逻辑快照。

`reload({ providerId? })` 返回每个 Provider 的 `servedFrom`、修订、刷新状态和可选错误。一个刷新失败不回滚其他 Provider 已成功发布的新视图，也不删除仍可读取的旧 current。
