# KnowledgeReader

<span className="cg-status">Available</span> <span className="cg-status">Contract-only</span>

`canRead(ref)` 同步决定是否支持一个非本地来源。Core 选择第一个匹配的自定义 Reader；内置本地 Reader 优先处理 `relative-file`。

`read(ref, context, { maxBytes })` 返回精确 bytes、contentType、contentId 和 source。Reader 必须：

- 不替换声明 locator；
- 遵守 Core 下发的最大字节；
- 使 `contentId` 对应真实返回 bytes；
- 不把 `sourceContext.knowledgeRootDir` 暴露到公共响应；
- 自己回收 I/O、网络和句柄。

无匹配 Reader 使用 `CG_READER_UNCONFIGURED`；匹配 Reader 执行失败使用 `CG_READER_UNAVAILABLE` 或 Core 投影的读取错误。
