# 后续步骤

完成第一次查询后，按当前任务继续，不必一次接入所有扩展点。

| 目标 | 下一步 |
|---|---|
| 调整能力粒度 | [Choose Capability Granularity](../guides/choose-capability-granularity) |
| 设计父子、特化或相关关系 | [Design Relations](../guides/design-relations) |
| 让 Agent 按需读取本地文档 | [Add Local Knowledge](../guides/add-local-knowledge) |
| 暴露项目实际注册实例 | [Use Runtime](../guides/use-runtime) |
| 使用 MCP 渐进发现 | [Provider-owned MCP](../integrations/provider-owned-mcp) |
| 接入多个 Provider | [Work with Multiple Providers](../guides/multiple-providers) |
| 查字段、错误和预算 | [Reference](../reference/) |
| 诊断失败 | [Troubleshooting](../troubleshooting/) |

数据库权威、能力召回、知识检索和远程 Reader 在 `0.1.0` 中提供公开合同，但没有内置真实后端。只有在你的 Provider 配置了对应 Adapter 时，相关原语才可用。
