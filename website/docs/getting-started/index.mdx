# 快速开始

本分区面向第一次接入的 Provider 作者和框架维护者。前两步在一个空 Node.js 项目中完成能力发现；API/MCP 是随后按需选择的集成方式。

1. [安装](./installation)包并确认 Node.js 版本。
2. [创建第一个 Provider](./first-provider)，只定义一个 Provider、一个能力并验证目录结果。
3. 按任务选择[渐进发现与按需读取](../guides/progressive-discovery)、[设计 Provider API](./provider-owned-api)或[Provider 自有 MCP](../integrations/provider-owned-mcp)；不必先完成所有增强能力。

| 你现在的目标 | 前置条件 | 验证后得到什么 |
|---|---|---|
| 确认环境能加载包 | 支持的 Node.js 和一个空目录 | [安装](./installation)：入口输出 `function` |
| 第一次发现能力 | 包已安装；不需要克隆仓库 | [创建第一个 Provider](./first-provider)：两个 JSON、一个脚本、只有一个能力的 Catalog |
| 从旧版本升级 | 已有 1.0.0 定义或 Adapter | [迁移清单](./installation#从-100-迁移到-101)：替换旧 Schema、补 role 和八类关系，再重新发现修订 |

前两项都有页面材料还原后的自动执行验证。Runtime、知识检索和 MCP 都不是最小发现的前置。

**当前边界**：Core 不执行能力，也不替 Provider 设计认证、MCP 工具名称或 Agent 意图路由。
