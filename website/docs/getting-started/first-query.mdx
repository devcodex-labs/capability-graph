# 执行第一次查询

<span className="cg-status">可运行</span>

查询从平坦目录开始，而不是一次暴露整张图。调用方先获取可判别的主能力，再依据意图选择能力并进入详情或关系。

```ts
const provider = graph.forProvider('acme.http');

const catalog = await provider.listCatalog({ limit: 20 });
const requiredStaticRevision = catalog.meta.staticRevision;

const detail = await provider.getCapabilities(
  ['route.http'],
  { requiredStaticRevision }
);

const neighbors = await provider.getNeighbors(
  'route.http',
  { requiredStaticRevision }
);
```

## 读取顺序

1. `listCatalog()` 返回用途、使用时机和关键区别，用于第一轮选择。
2. `getCapabilities()` 返回已选能力的完整静态定义。
3. `getNeighbors()` 只展开请求的关系组，不自动遍历整张图。
4. 调用方根据任务继续选择；Graph 不替 Agent 作业务决策。

始终检查 `meta.completeness`、`warnings` 和 `nextCursor`。部分结果不是全集，已知 ID 也可以直接查详情，无需强制先列目录。

```ts
try {
  // queries
} finally {
  await graph.close();
}
```

`close()` 释放 Core 持有的权威视图句柄。它不取消已经交给 Adapter 的底层任务。
