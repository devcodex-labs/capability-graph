# Node.js 中使用 Core

<span className="cg-status">可用</span>

主包提供 ESM 根入口和 TypeScript 声明：

```ts
import {
  CapabilityGraph,
  CapabilityGraphError,
  type OpenConfig
} from '@devcodex/capability-graph';
```

前置是 G0 的两个定义文件。将两个 TypeScript 片段放在同一个项目根脚本中，由当前程序创建/关闭 graph；它不是 HTTP Server，若用 JavaScript，去掉 type 导入和 OpenConfig 注解即可。

```ts
import { fileURLToPath } from 'node:url';
const config: OpenConfig = {
  hostAllowedProviders: ['acme.http'],
  integrationEnabledProviders: ['acme.http'],
  providers: [{ providerId: 'acme.http', authority: {
    kind: 'file', rootDir: fileURLToPath(new URL('./providers/acme-http/', import.meta.url))
  } }]
};
const graph = await CapabilityGraph.open(config);
try {
  const providers = await graph.listProviders();
  const catalog = await graph.listCatalog({ limit: 40 });
  const bound = graph.forProvider('acme.http');
  const detail = await bound.getCapabilities(['route']);
  console.log({ catalog, detail });
} catch (error) {
  if (error instanceof CapabilityGraphError) {
    console.error(error.code, error.nextAction);
  }
  throw error;
} finally {
  await graph.close();
}
```

config 指定唯一来源；显式绑定已知 Provider，不把目录第一项当默认来源。G0 的 Catalog 只有 route，detail.results[0].ok 应为 true；Promise 成功不代表每项成功，检查 results 和 meta。open 失败时没有 graph 可关闭，应修正配置后重试；后续失败仍通过 finally 释放资源。完整可运行 JavaScript 入口见[最小教程](../getting-started/first-provider)。

短脚本可执行完即关闭；长运行 API/MCP 应在服务启动时打开图、停机时关闭，不要为每次请求创建或关闭共享实例。接入方负责认证与请求范围，Core 负责来源校验、有界查询和修订一致性。

`forProvider()` 只绑定查询范围，不拥有来源句柄。完整生命周期与 `BoundProviderGraph` 差异见 [Core 与生命周期](../reference/capability-graph)。
