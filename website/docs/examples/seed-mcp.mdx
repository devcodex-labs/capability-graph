# Seed MCP

<span className="cg-status">Runnable</span>

Seed MCP 是独立私有包。它安装 MCP SDK 和 Zod，但这些依赖不会进入 Capability Graph 主包。

```sh
cd examples/seed-mcp
npm ci --ignore-scripts
npm test
```

示例的协议测试验证工具发现和调用。工具只是 Provider 接入参考，不冻结所有 Provider 都必须使用相同名称或数量。

[查看源码](https://github.com/devcodex-labs/capability-graph/tree/main/examples/seed-mcp)
