# VextJS 集成

<span className="cg-status">仅合同</span>

仓库提供 `examples/vextjs/` 的原生目录导出器、stdio 客户端和运行快照适配器。默认回归验证接入合同；真实验证需要固定的 VextJS 安装快照及仓库外实际项目。它们是源码示例，不属于 Core 的 npm 导出。Core 继续保持框架无关。

## 来源与角色

Provider 从原生 MCP 回读 capability、rule、recipe、knowledge、workflow，保留原生 ID、status、正文、catalog digest 和来源身份，生成稳定的 `native.c03` 等身份与可读取的 relative-file 文档。`vext://` 仅是原生来源引用，由导出器转换为实际文件；不是内核支持的 URI Reader。

原生 MCP 缺少分页枚举全部 knowledge 的资源。本例从固定安装快照的目录模块获取发现材料，再核对原生 MCP 的身份、摘要与正文。这个边界只对已核验的 schema 2 成立。`relatedIds` 是可选上下文，不据此推导 requires；原生 Recipe 的 available 也不表示 Core 会执行任务。

同来源重新导出内容稳定；来源更新后重新导出并 reload，宿主按 Provider 失效/重建检索器。不能只用 package.version 固定来源：VextJS main 的固定提交与 npm 2.0.0 虽然版本文本相同，目录与依赖可能不同。

## 实际执行入口

克隆本仓库并在根运行 `npm test`，在仓库外安装固定 VextJS 快照、准备实际项目，再将占位路径替换为真实目录：

```bash
node scripts/validation/vextjs.mjs /external/fixed-vextjs /external/project SOURCE_ID
node scripts/validation/vextjs-session.mjs /external/fixed-vextjs
```

第一项回读原生 MCP、导出 Provider、运行独立检索任务并核验片段偏移和运行证据；第二项通过实际 TCP HTTP 验证 Session、CSRF、失效/退出和 Store 关闭。临时应用、Provider、日志和报告放在项目同级专用目录；正式入口在根 scripts/，固定任务及回归在根 test/。外部框架与数据库不加入 website。

## 运行证据的覆盖边界

| 来源 | 能证明什么 | 需要额外核验什么 |
|---|---|---|
| OpenAPI | 公开 HTTP 契约 | 隐藏路由、实际业务副作用、Job worker 与进程存活 |
| project inspect | 固定项目身份、源码/构建观察 | 不能把当前源码修订当旧部署来源 |
| runtime inspect | 启动实例、状态、worker/reload/event 快照 | stopped 快照仍可存在；liveness=unverified 不等于进程在线 |
| 实际 HTTP/Redis/MongoDB/浏览器 | 对应请求、记录与交互 | 只证明执行过的场景与固定来源 |

`VextNativeRuntimeAdapter` 保留 partial/unknown/unverified。可信部署来源缺失时不会复制查询 Static Revision；运行游标拒绝快照变化。目录实例与 Snapshot 可用不代表完整运行图。

## 分段与检索

大文档通过 [正文分段接口](../reference/knowledge#正文分段读取)读取，模型决定范围和是否继续。每页分别返回全文和本页哈希；总大小不作为不可读门槛。参考检索器通过 scan 消费大正文，不要求人工拆文档。

固定任务来自根 `test/fixtures/vextjs/retrieval-tasks.json`，期望身份独立于排名。验证比较原生 MCP 和 CG 的召回、未知需求、知识片段、响应量及 P50/P95，模型调用为零。词法召回对否定、同义表达与中文单字容易产生误推荐，不能把这组基线称为 Agent 任务成功率。

真实 Redis Jobs、MongoDB 业务、热重载/cluster、浏览器 SSR/水合与纯 HTML、Cookie/Session 的验证须使用对应固定框架及服务，执行记录另存仓库外。默认 `npm test` 中的受控合同测试不能替代这些实际执行，也不能据此宣称支持任意版本或平台。

已单独核验 npm `vextjs@2.0.0`：其 CLI 不包含 `mcp`，因此不能使用原生 schema 2 Provider/Runtime 接入；该发布包的实际 TCP Session/CSRF 场景可另行验证。此原生接入当前适用于固定 main 快照 `ef926649926e17543562b8169982fa1786285ecf`，不把同版本号的发布包视为等价来源。
