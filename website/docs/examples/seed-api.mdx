# Seed API 示例

<span className="cg-status">可运行</span>

Seed API 依次执行 Provider 列表、目录、详情、邻居、本地知识和可选 Runtime 查询，并在 `finally` 中关闭图实例。它证明普通 API 可以直接复用 Core，而不需要 MCP SDK。

```sh
npm test
```

示例由根测试编译并执行，输出中的选择列表由调用方明确提供，关系不会自动选择知识。
